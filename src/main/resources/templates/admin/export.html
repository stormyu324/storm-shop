上传到平台的步骤

  1. 在平台卖家后台下载你所在类目的官方批量上架模板（不同类目必填项不同）。
  2. 用 Excel 打开本站导出的表格，把对应列复制到官方模板里；亚马逊表格的列名与模板字段名一致，可按列名对照。
  3. 补上模板里类目特有的必填项（例如商品类型、目标人群、尺码体系等），然后在卖家后台上传。
  4. 平台审核的报错一般会指出行号和字段，回到本站改好资料后重新导出即可。

提示：平台的模板和规则会更新，请以卖家后台下载的最新模板为准。
