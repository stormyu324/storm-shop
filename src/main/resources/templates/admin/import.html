第 1 步：下载模板并填写

下载 CSV 模板

用 Excel / WPS 打开模板填写，完成后“另存为 CSV”格式。只有名称和售价必填，用不到的列可以留空或删掉。表格里留空的单元格不会覆盖已有资料。也可以在“平台导出”页下载现有商品的通用资料表，改完再导回来。列说明：

名称必填
SKU可选。与已有商品相同则更新该商品，否则新建；留空自动生成
分类可选。填写分类名称，不存在会自动创建
售价必填，例如 59.9
原价可选，显示为划线价
库存可选，整数；新商品默认 0
状态可选：上架 / 下架 / 草稿；留空使用下方的默认状态
图片可选，图片网址，多张用 | 分隔，第一张为主图
描述可选
英文标题 / 英文描述可选，英文前台和导出平台时使用
英文卖点可选，多条用 | 分隔，最多 5 条
美元售价可选；留空时按汇率从人民币价格换算
品牌 / 颜色 / 尺码 / 材质可选
款号可选。同款不同颜色或尺码的商品填同一个款号，导出亚马逊时自动生成变体
重量(g) / 长宽高(cm)可选，包装后的重量和尺寸
条码可选，12 位 UPC、13 位 EAN 或 14 位 GTIN

第 2 步：上传文件

自动识别 UTF-8 和 GBK 编码，Excel 直接保存的文件也可以导入。
