# 第二批商城功能

本分支基于第一批订单服务功能开发，包含会员中心、优惠券、运营报表、员工权限和后台操作记录。

## 会员中心

访问 /account，通过邮箱验证码注册或登录。沿用第一批 SMTP 配置。
验证码 10 分钟有效，最多尝试 5 次且成功后失效。
会员会话最长 24 小时，同时受服务器 Session 空闲时间限制。
会员可维护最多 20 个有效地址、默认地址、停用地址，以及最多 200 个有效收藏。
结算页可选用已保存地址，会员下单邮箱以当前已验证账号为准。
历史订单按已验证邮箱匹配，包括以前以该邮箱下的游客订单。
会员可从历史订单进入第一批订单查询页查看物流和申请售后。
收藏支持重复点击，并过滤已下架商品。
验证码发送和 IP 限流沿用单实例队列与限流方案，真实发送需配置 SMTP。

## 优惠券

后台 /admin/coupons，允许管理员和运营岗位管理。
支持 FIXED 满减金额、PERCENT 百分比减免，以及人民币或美元单一币种。
20% 表示减免商品金额的 20%，优惠金额最多抵扣商品金额。
运费与包邮门槛按优惠前商品金额计算。
支持起止时间、商品金额门槛、启用状态、总使用次数上限。
创建后代码、类型、金额与币种保持固定，可更新时间、门槛、上限和启用状态。
结算页和 /api/shipping/quote 接受 couponCode，服务端下单时重新校验。
每单使用一个优惠码。下单预占使用名额，待付款订单也会占用名额。
取消订单或整单退款成功后释放名额，一张订单只释放一次。
优惠券锁定和订单库存更新在同一数据库事务中完成。
Stripe Checkout 收款使用优惠后的金额。总额为零的订单直接完成付款确认。
历史订单新增折扣字段为空时按零折扣处理。

## 运营数据

后台 /admin/analytics，允许管理员和运营岗位查看。
日期范围最多 366 天，按订单创建日期归集，人民币和美元独立统计。
展示创建订单数、付款订单数、含运费收款总额、已完成全额退款、净收款、付款客单价、
订单付款转化率、每日数据和已付款且未全额退款的热销商品件数。
付款以订单 paidAt 字段为准。线下订单实际到账后，由管理员在后台订单列表点击“确认收款”（客服等其他角色看不到这个按钮），已发货或已完成的订单可补录。补录会记录当前确认时间，报表仍按下单日期归集。
退款按查询时订单 REFUNDED 状态归集，反映指定下单批次的当前结果。

## 员工权限和审计

后台 /admin/staff 可创建、停用员工或重置密码，初始密码至少 12 字符且不超过 72 字节。
新密码只在请求中提交，数据库保存哈希，员工查询接口不返回密码或密码哈希。
部署配置中的初始管理员保持由环境变量管理。

- CATALOG 商品岗位管理商品、分类、批量导入、资料导出、AI 商品资料和配送规则。
- SUPPORT 客服岗位查看订单、发货、登记售后。
- OPERATIONS 运营岗位管理优惠券和查看运营数据。
- ADMIN 管理员拥有全部权限，包括退款审批、员工和操作记录。

所有权限由后端接口执行，前端按角色显示菜单。
密码、岗位或启用状态变化会撤销员工已有会话，需重新登录。
管理员无法通过该界面停用自己或移除自己的管理员权限。
/admin/audit 展示后台控制器写操作的操作人、接口模板、目标 ID、时间和响应状态。
审计不采集请求正文、密码、验证码、Cookie 或令牌。
构建后台使用 npm run build；仓库沿用静态后台资源与 Spring Boot 一起发布的方式。

## 验证

新增集成测试覆盖会员验证、地址和历史订单隔离、收藏幂等、优惠券并发名额、
作废与退款释放、服务端优惠成交金额、角色访问控制、员工会话撤销以及报表金额。
真实 SMTP 与 Stripe 联调仍应使用对应服务商的测试环境完成。
